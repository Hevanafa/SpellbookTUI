SpellbookTUI v0.1
By Hevanafa (Nov 2026)

A word search utility written in Free Pascal

This document is for releases and is different from readme.md, where the Markdown document is aimed towards developers and potential users

-- GETTING STARTED --

1. Extract the content of the ZIP file to a directory of your choice
2. Visit Peter Norvig's N-gram page:
   https://www.norvig.com/ngrams/
3. Find and download the file named count_1w.txt
4. Place the word list in the same directory as SpellbookTUI.exe
5. Run SpellbookTUI.exe

The reason why I don't include count_1w.txt is because the redistribution licence is uncertain

-- USAGE --

Enter a search term to search for words

Enter .help to list all the available commands
Enter .exit to exit the app

-- ACKNOWLEDGEMENTS --

SpellbookTUI uses the English word frequency list (count_1w.txt)
made available by Peter Norvig

The word list is not included in this distribution
